# Careem AI Challenge — Growth Decision Intelligence

**Chosen challenge: #1 Decision Brief Generator**

### One-liner
**From performance data to the next business decision — with evidence, prioritisation and an experiment plan.**

## Demo
This repository is ready for Streamlit Community Cloud.

Files:
- `app.py` — interactive prototype
- `synthetic_growth_data.csv` — synthetic growth dataset
- `synthetic_customer_segments.csv` — synthetic lifecycle/cohort dataset
- `insight_engine_prompt.md` — reusable LLM prompt
- `CASE_STUDY.md` — product rationale
- `100_WORD_SUMMARY.txt` — application submission copy


## What the app demonstrates
- Executive KPI dashboard
- Revenue/MAU/OPU/ARPU trends
- City performance
- Customer lifecycle segmentation
- Transparent guardrail engine
- Prioritised decision brief
- Experiment recommendation
- Synthetic-data safety

## Public dataset statement
No external dataset is required. The prototype intentionally uses synthetic data to avoid confidential information.
